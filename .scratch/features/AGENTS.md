# AGENTS.md — ExpenseKu feature development

New features follow **`.claude/skills/build-feature/SKILL.md`** (the owner runs it as
`/build-feature <idea>`): locate → grill one decision per turn → PRD in `docs/prd/` →
`.pen` proposal on page 05 → owner approves → build with tests + simulator check → move the
flow to page 02 → merge to `main`. The PRD's `Status:` line is the resume point.

The folders here (`daily-total`, `expense-search`, …) are the archive of the earlier
brief → ASCII wireframe → tech spec pipeline, which this replaced on 2026-10-03. Read them for
history only; `_template/` is retired.
